# 目的

## プロダクト
近年「バチェラーシリーズ」をはじめとする恋愛リアリティショーの流行により、「重要な局面でバラを贈る」という行為の認知が一般に広がっている。
これに伴い「バラの本数や色に秘められた意味(花言葉)」に対して、潜在的な関心を持つ層が増えていると推測される

本プロジェクトでは、上記のニッチながらも身近な知的好奇心を刺激し、「恋リア風のシチュエーションを模したインタラクティブなゲーム形式で、バラの本数の意味を楽しく学べる体験」を提供することを目的とする

## エンジニアリング
本プロダクトはGitHub Pages（フロントエンド完結）でのホスティングを想定しているため、物理的なリレーショナルデータベース（RDB）は使用しない

しかし、個人開発の技術検証として「美しく正規化されたリレーショナルデータ設計」の思想をフロントエンドのデータ構造（JSON / オブジェクト）に徹底的に適用することを実践する

安易に扱いやすい1つの大きなJSONを作るのではなく、概念ごとにエンティティを切り出し、主キー（PK）や外部キー（FK）の関係性を意識したデータ構造を構築することで、将来的にいつでもRDB移行・マッピング可能な状態かつ、論理的で堅牢なデータ設計を検証する

# ターゲット

- 恋リアが好きな年代
- 花言葉に興味がある20〜30代
- 隙間時間に遊ぶライトユーザー

# 提供価値（ユーザーが得られる体験）

1. 実用的な「バラの本数の花言葉」を楽しく暗記できる
   単なる暗記シートではなく、恋リア風のシチュエーション問題と組み合わせることで、記憶に残りやすく、実生活やエンタメ鑑賞（バチェラー等）がより楽しくなる知識を自然に習得可能
2. 隙間時間を消費しない、手軽な知的エンタメ体験
   1プレイが数分で完結するため、通勤電車の1駅間や、日常のちょっとした待ち時間に、脳に程よい刺激と「へぇ！」というアハ体験を提供する

# 独自の強み（他プロダクトとの差別化）

1. 「インストールの手間ゼロ」で瞬時に遊べる圧倒的な手軽さ
   Webブラウザ（GitHub Pages）で配信するため、アプリストアからのダウンロードやアカウント登録が一切不要です。SNSでURLを見つけてから「3秒でプレイ開始できる」気軽さが最大の強みです。
2. あらゆる環境に対応するマルチデバイス・マルチOS設計
   特定のプラットフォームに依存しないため、ユーザーの環境を選びません。
   - 対象OS: iOS, Android, Windows, Mac
   - 対象デバイス: スマートフォン(SP), タブレット, PC
